# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Arabic-speaking software developers, from beginners to experts. Typical situations: they inherited a codebase, vibe-coded one they don't fully understand, joined a team, or teach others. The main reading situation is a desktop screen beside the code editor: the developer keeps the page open as a map while reading the real files.

## Product Purpose

`/explain` is a Claude skill that reads a real codebase and produces one interactive Arabic page explaining it: what the project is, its parts and layers, how one request travels through it, its database, its history, the vocabulary, where to change things, and starter exercises. Success: a developer understands an unfamiliar project faster and knows which file to open next.

## Positioning

Arabic-first and grounded in the actual code. Every class name, file path, line number and commit on the page is verified against the repository, and the explanation is carried by an analogy drawn from the project's own domain. Existing codebase explainers are English-only or generic.

## Operating Context

- Generated by Claude Code from a JSON data file and a fixed HTML template (`assets/template.html`, built by `scripts/build.py`).
- Viewed as a claude.ai Artifact or opened as a local HTML file.
- Read mostly on desktop beside an editor; also shared as a link and occasionally shown in teaching.

## Capabilities and Constraints

- One self-contained HTML file. Fonts from Google Fonts only; no other remote assets; no paid services.
- Right-to-left Arabic, with code identifiers, paths and snippets left-to-right.
- Light and dark themes through tokens; must work at phone width without page-level horizontal scroll.
- The layout is fixed across projects; only the data changes. Sections: header, analogy cast, layer map, step-by-step flow with travelling ball, database map, parts/screens, project story, glossary, change table, exercises, folder tree, optional Claude-drawn SVG figures.
- Beginner/expert switch hides technical detail for beginners.
- Open source under MIT; must work for anyone without extra accounts.

## Brand Commitments

- Name: `/explain` (the slash command). Arabic subtitle used so far: «شرح المشاريع بالعربية».
- The page carries its own recognizable identity on every project, like a series, while project content changes.

## Evidence on Hand

- Real generated pages exist for the author's own private projects; they are not part of this repository and must not be published.
- `examples/sample.json`: a fictional library app for public demos.
- No testimonials, user counts or benchmarks exist; do not invent any.

## Product Principles

1. Truth over polish: nothing on the page may contradict the code.
2. The map serves the reader beside the editor: scannable, precise, quick to find a part and its file.
3. Plain Arabic first, technical precision on demand.
4. One consistent identity across every project, so readers learn the page once.
5. Free and portable for anyone who installs it.

## Accessibility & Inclusion

Arabic RTL reading order, keyboard-operable interactive parts, readable contrast in both themes, reduced-motion support.
